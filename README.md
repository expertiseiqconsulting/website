# ExpertiseIQ — fichiers pour GitHub Pages

## Contenu de ce dossier
- `index.html` → votre site (page d'accueil)
- `404.html` → page d'erreur personnalisée, servie automatiquement par GitHub Pages
- `sitemap.xml` → plan du site pour les moteurs de recherche
- `robots.txt` → autorise les moteurs de recherche à indexer le site

## Avant de déployer
Dans `sitemap.xml` et `robots.txt`, remplacez `VOTRE-DOMAINE` par votre vraie adresse :
- Si vous utilisez l'URL GitHub par défaut : `votrepseudo.github.io/expertiseiq` (adaptez selon le nom de votre dépôt)
- Si vous ajoutez un nom de domaine personnalisé plus tard : `www.votredomaine.fr`

## Déployer
1. Téléversez les 4 fichiers à la racine de votre dépôt GitHub (pas dans un sous-dossier)
2. Settings > Pages > Source : "Deploy from a branch", branche `main`, dossier `/ (root)`
3. Votre site est en ligne en 1-2 minutes

## Mettre à jour le site plus tard
Éditez `index.html` directement depuis l'interface GitHub (icône crayon) ou redemandez-moi une nouvelle version, puis remplacez le fichier dans le dépôt.

## Informations légales encore à compléter
Dans `index.html`, section mentions légales : SIRET, statut juridique et adresse du siège sont encore des placeholders à remplacer par vos vraies informations.
